# Social Media Platform MVP

PulseSpace is a starter MVP for a creator-first social platform that combines:

- TikTok-style discovery
- Instagram-style profiles, social identity, and messaging
- YouTube-style creator studio, analytics, and monetization readiness

## Run Locally

```powershell
cd "C:\Users\sinha\OneDrive\Desktop\sm platform"
npm run dev
```

Then open:

```text
http://localhost:4173
```

The app has no external dependencies yet. It is a static frontend with mock data and a tiny Node server.

## Current MVP

- Feed with post cards
- Discover grid for short-form content
- Composer modal
- Community cards
- Inbox mockup
- Creator studio metrics
- Search filter
- Like, save, follow, and publish interactions
